# Kirimlaju SQL Practice Lab

Aplikasi latihan PostgreSQL dengan 75 business question dari dataset logistik Kirimlaju, hasil query langsung, validasi jawaban, schema explorer, dan progres belajar lokal. UI mengikuti Sedukopi SQL Practice Lab. Dibangun dengan HTML/CSS/JavaScript, Flask, Gunicorn, PostgreSQL, GitHub Pages, Render, dan Neon.
